# practica-01-github-html
Primera práctica de HTML y control de versiones con GitHub

## Propósito

El propósito de este repositorio es aprender a utilizar GitHub, subir archivos HTML y comprobar el funcionamiento del historial de versiones.

Este repositorio contiene una página web creada con HTML. La página incluye información sobre mi trabajo como monitor de gimnasio y sobre el desarrollo de mi aplicación de fitness.
